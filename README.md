Mod archives and previews for a Dota 2 mod manager, mirrored from the
[Dota2PornFxWeb](https://github.com/h6rd/Dota2PornFxWeb) catalog.

Previews and catalog data are in this repository. The archives are attached to a release per
category, because a repository will not take a file over 100 MB and some of them are larger.
